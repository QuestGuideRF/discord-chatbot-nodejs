# Чат-бот для Discord на Node.js

`index.js` создаёт клиент Discord, конструктор команд и подключение к MongoDB через Mongoose. `play.js` содержит обработчик команды воспроизведения и очередь песен для голосовых каналов.

## Структура

- [`index.js`](index.js) — конфигурация клиента, регистрация обработчиков и точка входа.
- [`play.js`](play.js) — поиск видео, очередь, воспроизведение через `@discordjs/voice`.

**Статус:** фрагмент Discord-бота, не полноценная запускаемая сборка. Отсутствуют `package.json`, `utils/loader`, `utils/logger` и локальная конфигурация, импортируемая как `../config`. Для запуска потребуются Node.js, MongoDB, `.env` с `DISCORD_TOKEN` и `MONGODB_URI`, а также реализация загрузки команд и событий. `play.js` — обработчик музыкальной команды; его работа зависит от внешних библиотек и доступности аудиопотока.
